## Research question

How can statistical and machine-learning methods support interpretable screening for anomalous standardized-test results?

## Motivation

Screening anomalous standardized-test results requires methods that are both statistically useful and interpretable for review. This project addressed that need in the context of Chile's university selection exam.

## Approach

The project developed an outlier-detection protocol that combined statistical discrepancy measures, clustering-based screening, and outlier-detection models into a single interpretable anomaly score for each test taker.
