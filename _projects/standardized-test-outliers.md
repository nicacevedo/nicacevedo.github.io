## Research question

How can statistical and machine-learning methods support interpretable screening for anomalous standardized-test results?

## Project overview

This project developed an outlier-detection protocol for Chile's university selection exam. It combined statistical discrepancy measures, clustering-based screening, and outlier-detection models into a single interpretable anomaly score for each test taker.
