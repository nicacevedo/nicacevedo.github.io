# Nicolás Acevedo Villena — academic website

This repository contains the source for [nicacevedo.github.io](https://nicacevedo.github.io), Nicolás Acevedo Villena's personal academic and research website.

The site is built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme, and is deployed through the repository's existing GitHub Actions workflow.

For local development, use the repository's Docker workflow (`docker compose up`) or a Ruby environment with the dependencies in `Gemfile`, then run `bundle exec jekyll serve`.
